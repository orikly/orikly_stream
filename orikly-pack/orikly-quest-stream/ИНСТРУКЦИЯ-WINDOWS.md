# Orikly Stream на Windows (основной компьютер для уроков)

Windows — основной компьютер. Mac — для разработки. Туннель `stream` один на оба компьютера и **работает только на одном за раз**. Если он запущен на обоих, Cloudflare делит очки между ними, и часть очков пропадает.

На Windows всё уже настроено раньше: служба туннеля `cloudflared`, программа-сервер в своей папке рядом с `orikly-server.json` (там ключ). Ниже — как вернуться на Windows и обновить программу.

---

## 1. Выключить туннель на Mac

1. На Mac закройте окно Терминала, где работает `cloudflared tunnel run …` (или нажмите в нём Ctrl+C).
2. Закройте окно сервера `orikly-server-mac`.
3. Cloudflare → **Networking → Tunnels → `stream` → Replicas**: Mac должен исчезнуть в течение минуты.

## 2. Запустить туннель на Windows

1. Пуск → наберите `PowerShell` → правой кнопкой → **Запуск от имени администратора**.
2. Выполните:
   ```
   Start-Service cloudflared
   ```
3. Проверка:
   ```
   Get-Service cloudflared
   ```
   В колонке Status должно быть **Running**.
4. В Cloudflare в **Replicas** — только `DESKTOP-IAG08AS`, статус **Healthy**.

Если пишет, что служба `cloudflared` не найдена: Cloudflare → `stream` → **Add a replica** → **Windows** → скопируйте команду `cloudflared.exe service install eyJ…` и выполните её в том же PowerShell от администратора. Токен `eyJ…` никому не пересылайте.

## 3. Обновить программу-сервер

1. Закройте окно старого `orikly-server.exe`, если оно открыто.
2. Положите новый `orikly-server.exe` **в ту же папку**, где лежит старый и `orikly-server.json`. Замените старый файл.
3. Двойной клик. Если Windows скажет «Система Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**.
4. В окне должно быть:
   - `Key from …\orikly-server.json: N characters.` — ключ прочитан из старого файла, вводить заново не нужно;
   - `Log file: …\orikly-log-<дата>.txt` — журнал фризов и трафика;
   - строки `connected: …` от очков (в течение 30 секунд).
5. Сам откроется браузер со страницей `http://localhost:8090`. Нужен **Chrome** (запись в папку работает только в нём). Если открылся другой браузер — скопируйте адрес в Chrome.

## 4. Проверка

- `https://stream.orikly.org/push` → **`forbidden`** — туннель и сервер работают.
- На странице плитки очков → **Start all**.
- Вверху страницы — **FPS** (10 / 15 / 20). Действует на очках с приложением 0.4.8 и новее; более старые шлют 10.

## 5. Записи на Google Диск

1. Установите «Google Drive для компьютера» (google.com/drive/download) и войдите аккаунтом ассоциации. Появится диск **G:**.
2. На странице: **Choose folder…** → **G:** → **Мой диск** → нужная папка → **Выбрать папку**. При первом Start Chrome спросит разрешение на запись — разрешите.

## 6. Чтобы ноутбук не засыпал

- Пока работает программа-сервер, Windows сама не засыпает и не гасит экран.
- **Крышка:** закрытая крышка всё равно усыпляет ноутбук. Либо держите крышку открытой, либо: Панель управления → Электропитание → **Действие при закрытии крышки** → «Действие не требуется» (для «От сети» и «От батареи»).
- **Не кликайте в окно сервера для выделения текста** — в новой версии это уже не останавливает поток, но окно лучше просто свернуть.

---

## Каждый урок

1. Ноутбук подключён к интернету.
2. Двойной клик по `orikly-server.exe` → откроется Chrome.
3. **Start all**. Клик по картинке — на весь экран, Esc — назад.
4. В конце **Stop all** (файлы сохранятся), потом закройте окно сервера.

## Если что-то не работает

| Что видно | Причина и что делать |
|---|---|
| Страница пишет «Server program is not running» | Не запущен `orikly-server.exe`. |
| `address already in use` | Сервер уже запущен в другом окне. Закройте лишнее. |
| `https://stream.orikly.org/push` → 502 | Туннель работает, сервер нет: запустите `orikly-server.exe`. |
| → 1033 / 530 | Туннель не запущен: п. 2. |
| Часть очков не появляется, в Replicas два компьютера | Туннель ещё работает на Mac: п. 1. |
| `rejected a headset with a wrong key …` | Ключ в `orikly-server.json` ≠ `STREAM_KEY`. Строка покажет длину ключей и место расхождения (сам ключ не печатается). |
| Фризы | Пришлите файл `orikly-log-<дата>.txt` из папки программы. |
