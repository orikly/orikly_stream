# Трансляция через интернет — настройка по шагам

Схема: очки (школьный Wi-Fi) → интернет → Cloudflare → ноутбук с Windows (интернет с iPhone).
Ноутбук — сервер: на нём работает программа `orikly-server.exe`. Cloudflare даёт ему постоянный адрес `stream.ВАШ-ДОМЕН`.

Ниже `ВАШ-ДОМЕН` — домен ассоциации, например `orikly.org`.

---

## Шаг 1. Домен ассоциации → Cloudflare (один раз)

Cloudflare должен управлять «адресной книгой» домена (DNS). Сайт и почта ассоциации продолжат работать, если записи перенесутся правильно. **Этот шаг делайте внимательно.**

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. **Add a domain** (Добавить сайт) → введите `ВАШ-ДОМЕН` → план **Free**.
3. Cloudflare сам найдёт существующие записи DNS и покажет список.
   **Сравните его с настройками DNS там, где куплен домен**: должны быть все записи, особенно `MX` (почта), `A`/`CNAME` (сайт) и `TXT`. Если чего-то не хватает, добавьте вручную, прежде чем идти дальше.
4. Cloudflare покажет два своих адреса nameserver (вида `xxx.ns.cloudflare.com`).
   Там, где куплен домен, в настройках **Nameservers / DNS-серверы** замените старые адреса на эти два.
5. Подождите. Обычно это от 15 минут до нескольких часов, иногда до 24. Когда всё готово, Cloudflare пришлёт письмо, что домен **Active**.

---

## Шаг 2. Туннель Cloudflare на ноутбуке (один раз)

1. В Cloudflare: **Zero Trust** (в меню слева) → **Networks → Tunnels** → **Create a tunnel**.
   Если Zero Trust попросит выбрать план, выберите **Free** (0 $). Он может попросить карту, но денег не спишет.
2. Тип **Cloudflared** → имя `orikly` → **Save tunnel**.
3. Выберите **Windows**. Cloudflare покажет:
   - ссылку на установщик `cloudflared` — скачайте и установите;
   - команду вида `cloudflared.exe service install eyJ...` (длинная строка).
   Откройте **Командную строку от имени администратора** (Пуск → `cmd` → правой кнопкой → «Запуск от имени администратора»), вставьте эту команду и нажмите Enter.
   Туннель запускается сам вместе с Windows, и запускать его вручную больше не нужно.
4. В Cloudflare внизу появится коннектор со статусом **Connected**. Нажмите **Next**.
5. **Public Hostname**:
   - Subdomain: `stream`
   - Domain: `ВАШ-ДОМЕН`
   - Service: Type **HTTP**, URL `localhost:8090`
   → **Save**.

---

## Шаг 3. GitHub: новый секрет и новые файлы

1. Settings → Secrets and variables → Actions → **New repository secret**:
   - Name: `RELAY_URL`
   - Secret: `wss://stream.ВАШ-ДОМЕН/push`
2. Загрузите обновлённый проект: в корне репозитория **Add file → Upload files** → перетащите папку `orikly-pack` из архива → **Commit changes**. Файлы заменятся.
3. Замените файл сборки: откройте `.github/workflows/build.yml` → карандаш (Edit) → выделите всё и удалите → вставьте текст из `build.yml` из архива → **Commit changes**.
4. **Actions → Build APK → Run workflow** → версия `0.3.0`.
   В Release `v0.3.0` будет два файла: `orikly-quest-stream.apk` и `orikly-server.exe`.
5. HMS обновит приложение на очках по той же ссылке.

---

## Шаг 4. Ноутбук: программа-сервер (один раз)

1. Скачайте `orikly-server.exe` из Release (или возьмите из архива) и положите в отдельную папку, например `Документы\Orikly`.
2. Двойной клик. Windows может предупредить «Windows защитила компьютер», потому что программа без цифровой подписи → **Подробнее** → **Выполнить в любом случае**.
3. При первом запуске программа спросит ключ: введите тот же `STREAM_KEY`, что в GitHub, и нажмите Enter. Ключ сохранится рядом в файле `orikly-server.json`.
4. Откроется Chrome со страницей `http://localhost:8090`. Чёрное окно программы не закрывайте: пока оно открыто, сервер работает.

## Шаг 5. Google Диск (один раз)

1. Установите «Google Диск для компьютера» (Google Drive for desktop) и войдите аккаунтом ассоциации.
2. В Проводнике появится диск `G:`. Создайте папку, например `G:\Мой диск\Orikly записи` или папку на общем диске ассоциации.
3. На странице нажмите **Choose folder…** и выберите эту папку. Chrome её запомнит.

## Шаг 6. Очки (после обновления — один раз)

Откройте **Orikly Stream** → **Iniciar transmisión** → **Pantalla completa** → **Empezar**.
На экране приложения должна появиться строка **Servidor: conectado**.

---

## Каждый урок

1. Ноутбук подключён к интернету с iPhone.
2. Запустите `orikly-server.exe`. Откроется Chrome со страницей.
3. Очки появятся на странице сами, по именам. Нажмите **Start all**: пойдёт картинка и запись в папку Google Диска.
4. В конце **Stop all**, потом закройте окно программы.

На очках ничего не нажимаете, пока они не перезагрузятся.

---

## Если не работает

- **На странице «Server program is not running»** — не запущен `orikly-server.exe`.
- **На очках «Servidor: conectando…»**:
  - проверьте, что сервер на ноутбуке запущен;
  - в Cloudflare → Tunnels туннель должен быть **Healthy**;
  - в браузере на телефоне откройте `https://stream.ВАШ-ДОМЕН/push`. Ответ `forbidden` — значит, туннель работает. Ошибка Cloudflare (1033, 502 или 530) — значит, туннель или сервер не запущены.
  - в чёрном окне программы строка `rejected a headset with a wrong key` — ключ в `orikly-server.json` не совпадает со `STREAM_KEY` в GitHub. Исправьте файл (открыть Блокнотом) и перезапустите программу.
- **«Capture stopped — tap Iniciar on headset»** — захват на очках остановился (перезагрузка или каст Meta). Нужно один раз нажать «Iniciar» на очках.
