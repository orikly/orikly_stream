# Сервер на Mac (M1 и любые другие Mac)

Всё как на Windows, отличаются только три вещи: файл программы, установка туннеля Cloudflare и первый запуск.

Работать должен **один** компьютер-сервер. Если на Windows-ноутбуке тоже запущен туннель, Cloudflare будет отправлять часть очков туда, и они не появятся на Mac. Сначала остановите туннель на Windows (шаг 1).

---

## Шаг 1. Остановить туннель на Windows (если он там стоит)

На Windows: PowerShell **от имени администратора**:
```
cloudflared service uninstall
```
Если пишет, что `cloudflared` не распознан:
```
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" service uninstall
```
В Cloudflare → Tunnels → `stream_vr` → Replicas строка `DESKTOP-IAG08AS` пропадёт (это может занять минуту).

## Шаг 2. Туннель Cloudflare на Mac (один раз)

1. Нужен Homebrew. Проверьте в Терминале: `brew --version`. Если его нет, установите по команде с https://brew.sh (одна строка, Терминал спросит пароль от Mac).
2. Установите cloudflared:
   ```
   brew install cloudflared
   ```
3. Возьмите токен туннеля: Cloudflare → Tunnels → `stream_vr` → **Add a replica** → выберите **macOS**. Cloudflare покажет команду вида `sudo cloudflared service install eyJ...`. Скопируйте её целиком, вставьте в Терминал и нажмите Enter. Терминал спросит пароль от Mac: при вводе символы не видны, это нормально.
4. Через минуту в Replicas появится ваш Mac со статусом Healthy.

Туннель запускается сам вместе с Mac, и запускать его вручную больше не нужно. Маршрут (`stream.orikly.org` → `http://127.0.0.1:8090`) уже настроен и для Mac подходит без изменений.

## Шаг 3. Программа-сервер (один раз)

1. Возьмите `orikly-server-mac.zip` (из архива или из Release на GitHub) и распакуйте двойным кликом.
2. Создайте папку, например `Документы/Orikly`, и положите туда файл `orikly-server-mac`.
3. macOS не даст запустить программу из интернета без подписи Apple. Снимите запрет один раз — в Терминале:
   ```
   xattr -d com.apple.quarantine ~/Documents/Orikly/orikly-server-mac
   ```
   Путь должен совпадать с тем, куда вы положили файл. Можно набрать `xattr -d com.apple.quarantine `, а затем перетащить файл из Finder в окно Терминала: путь подставится сам.
   Если команда пишет `No such xattr`, значит, запрета и так нет, всё в порядке.
4. Двойной клик по `orikly-server-mac`: откроется окно Терминала.
   При первом запуске программа спросит ключ: введите тот же `STREAM_KEY` и нажмите Enter. Ключ сохранится рядом в `orikly-server.json`.
   Если файл `orikly-server.json` от Windows-версии у вас есть, просто положите его в ту же папку, и ключ спрашивать не будут.
5. Откроется Chrome со страницей `http://localhost:8090`. Окно Терминала не закрывайте: пока оно открыто, сервер работает.

## Шаг 4. Записи в Google Диск

1. Установите «Google Drive для компьютера» и войдите аккаунтом ассоциации.
2. На странице **Choose folder…** → выберите папку на Google Диске (в Finder слева раздел «Google Drive»).
3. **Если Chrome пишет, что папку открыть нельзя, потому что там системные файлы.** На Mac Google Диск лежит внутри системной папки `Library`, и Chrome иногда её не разрешает. Тогда:
   - выберите обычную папку, например `Фильмы/Orikly записи`;
   - в настройках Google Drive (шестерёнка → Настройки → «Мой компьютер» → **Добавить папку**) добавьте эту папку. Записи будут сами уезжать на Диск.

---

## Каждый урок

1. Mac подключён к интернету с iPhone.
2. Двойной клик по `orikly-server-mac`, откроется Chrome.
3. **Start all**.
4. В конце **Stop all**, потом закройте окно Терминала (или нажмите в нём Ctrl+C).

## Если не работает

- **На странице «Server program is not running»** — не запущен `orikly-server-mac`.
- **В окне Терминала `address already in use`** — программа уже запущена в другом окне Терминала. Закройте лишнее окно.
- **`https://stream.orikly.org/push` даёт 502 или 1033** — туннель не работает на этом Mac. Проверьте в Cloudflare, что в Replicas есть Mac со статусом Healthy и нет Windows-ноутбука.
- **Плитки не появляются, в окне `rejected a headset with a wrong key`** — ключ в `orikly-server.json` не совпадает со `STREAM_KEY`. Откройте файл в TextEdit, исправьте ключ и перезапустите программу.
