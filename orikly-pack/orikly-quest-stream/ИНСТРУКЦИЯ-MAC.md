# Orikly Stream на Mac (для разработки и проверок)

Основной компьютер на уроках — **Windows**. Mac — для разработки и проверок. Работают оба с **одним и тем же туннелем `stream`**, но **никогда одновременно**.

Почему так: туннель — как один телефонный номер. Если «трубка снята» на двух компьютерах, Cloudflare делит очки между ними, и часть очков пропадает с экрана. Поэтому:
- работаете на Mac → на Windows туннель остановлен (или ноутбук выключен);
- закончили на Mac → закрыли туннель на Mac, на Windows запустили снова.

На Mac туннель **не ставится службой** (не запускается сам). Вы включаете его вручную в окне Терминала и выключаете, закрывая окно. Так он не включится случайно, пока на уроке работает Windows.

На Mac работают две программы, каждая в своём окне Терминала:
- **cloudflared** (туннель) — принимает очки из интернета;
- **orikly-server-mac** (сервер) — принимает картинки и показывает их в Chrome.

---

## Часть 1. Один раз: убрать остатки прошлой попытки

Раньше на Mac был создан отдельный туннель `stream_vr_macos`. Его служба могла остаться на Mac.

1. Откройте **Терминал** (Cmd+Пробел → `Терминал` → Enter) и выполните по очереди:
   ```
   sudo cloudflared service uninstall
   ```
   ```
   sudo pkill cloudflared
   ```
   Спросит пароль от Mac. При вводе символы не видны, это нормально. Ошибки вроде «not installed» или «no process found» — тоже нормально.
2. Проверка:
   ```
   ps aux | grep [c]loudflared
   ```
   Пусто — хорошо.
3. В Cloudflare: **Networking → Tunnels** должен быть только туннель **`stream`**. Если там ещё есть `stream_vr_macos`, удалите его (три точки → Delete).
4. **DNS → Records**: если есть запись `stream-vr-mac`, удалите её. **Запись `stream` не трогайте.** Остальные записи (сайт, почта) тоже не трогайте.

---

## Часть 2. Один раз: токен туннеля

Токен — длинный пароль туннеля (начинается с `eyJ`). **Никому не пересылайте и не выкладывайте в GitHub.**

1. **dash.cloudflare.com → Networking → Tunnels → `stream`** → **Add a replica** → выберите **macOS**.
2. Cloudflare покажет команду `sudo cloudflared service install eyJ...`. **Эту команду не выполняйте.** Скопируйте из неё только длинную часть `eyJ...` и сохраните её в «Заметки» или в менеджер паролей.

---

## Часть 3. Программа-сервер (один раз)

1. Распакуйте `orikly-server-mac.zip` двойным кликом. Появится файл `orikly-server-mac`.
2. В Finder создайте папку **Документы → Orikly** и перенесите туда этот файл.
3. Снимите запрет macOS на запуск. В Терминале наберите (в конце — пробел):
   ```
   xattr -d com.apple.quarantine 
   ```
   Перетащите файл `orikly-server-mac` из Finder в окно Терминала (путь подставится сам) и нажмите Enter. Ничего не написал или написал `No such xattr` — хорошо.
   Без Терминала: двойной клик по файлу → «разработчик не может быть проверен» → **Системные настройки → Конфиденциальность и безопасность** → внизу **«Всё равно открыть»**.
4. Двойной клик по `orikly-server-mac`. При первом запуске программа спросит ключ: `Enter the access key…`. Введите **тот же ключ, что в секрете `STREAM_KEY`** на GitHub (вида `password_1234`) и нажмите Enter. Он сохранится в `Документы/Orikly/orikly-server.json`.
   Не помните ключ — на Windows откройте `orikly-server.json` (рядом с `orikly-server.exe`) в Блокноте и посмотрите строку `key`.

## Каждый раз: переключиться с Windows на Mac

1. **Windows: остановить туннель.** Либо выключите Windows-ноутбук, либо: Пуск → `PowerShell` → правой кнопкой → **Запуск от имени администратора** →
   ```
   Stop-Service cloudflared
   ```
2. **Mac: запустить туннель.** Новое окно Терминала (Cmd+N) → наберите `cloudflared tunnel run --token ` (в конце пробел) → вставьте токен из Части 2 → Enter.
   Через несколько секунд в окне появятся строки `Registered tunnel connection` — туннель работает. **Окно не закрывайте.**
3. В Cloudflare (**Tunnels → `stream` → Replicas**) должен быть **только Mac**. Если там ещё и `DESKTOP-IAG08AS`, значит, на Windows туннель не остановлен (п. 1).
4. **Mac: двойной клик по `Документы/Orikly/orikly-server-mac`.** Откроется ещё одно окно Терминала и Chrome со страницей `http://localhost:8090`.
5. **Проверка:** откройте `https://stream.orikly.org/push` → должно быть **`forbidden`**. Очки переподключатся сами в течение 30 секунд: в окне сервера появятся строки `connected: …`, на странице — плитки.

## Каждый раз: вернуться на Windows

1. **Mac:** закройте оба окна Терминала (туннель и сервер). Можно и в самом окне нажать Ctrl+C.
2. **Windows:** PowerShell от имени администратора →
   ```
   Start-Service cloudflared
   ```
   Проверка: в Replicas только `DESKTOP-IAG08AS`, статус Healthy. Если Windows-ноутбук был выключен, туннель запустится сам при включении.

## Записи и Google Диск (один раз)

1. Установите «Google Drive для компьютера» (google.com/drive/download) и войдите аккаунтом ассоциации.
2. На странице: **Choose folder…** → слева **Google Drive** → нужная папка → **Выбрать**. При первом Start Chrome спросит разрешение на запись — разрешите.
3. Если Chrome пишет, что папку открыть нельзя, потому что там системные файлы (на Mac Диск лежит внутри системной папки):
   1. В Finder создайте папку **Фильмы → Orikly записи** и выберите на странице её.
   2. Google Drive (значок в строке меню сверху) → шестерёнка → **Настройки** → **Мой Mac** → **Добавить папку** → **Orikly записи** → **Синхронизировать с Google Диском**.

Пока работает сервер, Mac не засыпает сам. **Крышку не закрывайте**: закрытая крышка всё равно усыпляет Mac.

## Что показывают плитки

- **Streaming · 10 fps** — сколько кадров в секунду реально доходит до компьютера.
- **⏱ 250 ms** — отклик канала очки → компьютер. Нормально 100–400 мс.
- **⚠ quality −2** — очки снизили качество, чтобы держать 10 кадров/с: интернет на пределе.
- **Нижняя серая строка — диагностика**, например `Quest 3 · system 1 fps · sent 10 fps · capture 960×960 · screen 4128×2208 72 Hz`:
  - **модель** очков;
  - **system** — сколько кадров в секунду отдаёт приложению сама система очков;
  - **sent** — сколько кадров в секунду очки отправили на компьютер (видно, когда нажат Start);
  - **capture** — размер захвата, **screen** — размер экрана и частота экрана.
  - Наведите мышь на строку: появятся версия приложения и версия системы очков.
  - Как читать: **system около 1** при надетых очках и движении головой → кадров не даёт сама система; **system 10 и больше, а Streaming мало** → кадры теряются по дороге. На лежащих очках или неподвижном экране system около 0–1 — это нормально, система шлёт кадры только при изменениях на экране.
- **Offline — headset not connected** — очки не подключены.
- **Capture stopped — tap Iniciar on headset** — захват на очках остановился. Нажмите Iniciar на этих очках.

То же самое видно на самих очках, на экране приложения: строка `Diagnóstico: sistema … fps · enviados … fps · …`.

## Если что-то не работает

| Что видно | Причина и что делать |
|---|---|
| Страница пишет «Server program is not running» | Не запущен `orikly-server-mac` — двойной клик по нему. |
| В окне сервера `address already in use` | Сервер уже запущен в другом окне Терминала. Закройте лишнее окно. |
| `https://stream.orikly.org/push` → 502 | Туннель работает, сервер нет: запустите `orikly-server-mac`. |
| → 1033 / 530 | Туннель не запущен ни на одном компьютере. На Mac — п. 2 «Переключиться на Mac». |
| Часть очков не появляется, в Replicas два компьютера | Туннель работает и на Windows. `Stop-Service cloudflared` на Windows. |
| В окне туннеля `Unauthorized` / `Tunnel not found` | Токен от другого (удалённого) туннеля. Возьмите токен заново: Часть 2. |
| `rejected a headset with a wrong key` | Ключ в `orikly-server.json` ≠ `STREAM_KEY`. Откройте файл в TextEdit, исправьте ключ, сохраните, перезапустите сервер. |
| `cloudflared: command not found` | `brew install cloudflared`. Если `brew` тоже не находится — выполните команды «Next steps» из установки Homebrew (`eval "$(/opt/homebrew/bin/brew shellenv)"`). |
