# Orikly Stream на Mac — полный гайд от туннеля до урока

Схема: **очки (школьный Wi-Fi) → интернет → Cloudflare → туннель → ваш Mac (интернет с iPhone) → Chrome**.

На Mac работают две программы:
- **cloudflared** (туннель) — принимает соединения от очков из интернета. Ставится один раз и дальше запускается сам вместе с Mac.
- **orikly-server-mac** (сервер) — принимает картинки и показывает их в Chrome. Запускаете перед уроком.

Что уже сделано и **не требует повторения**: домен `orikly.org` в Cloudflare, туннель `stream_vr` с маршрутом `stream.orikly.org → http://127.0.0.1:8090`, секреты в GitHub (`STREAM_KEY`, `RELAY_URL`), приложение на очках.

Время: около 30–40 минут один раз.

---

## Часть 1. Отключить туннель на Windows

Туннель должен работать **только на одном** компьютере. Если оставить его и на Windows, Cloudflare будет отправлять часть очков туда, и на Mac они не появятся.

1. На Windows-ноутбуке: Пуск → наберите `PowerShell` → правой кнопкой → **Запуск от имени администратора**.
2. Введите и нажмите Enter:
   ```
   cloudflared service uninstall
   ```
   Если пишет, что команда не распознана:
   ```
   & "C:\Program Files (x86)\cloudflared\cloudflared.exe" service uninstall
   ```
3. Проверьте в Cloudflare: **dash.cloudflare.com → Networking → Tunnels → `stream_vr`**. Через 1–2 минуты в таблице **Replicas** строка `DESKTOP-IAG08AS` должна исчезнуть, а статус туннеля станет **Down** или **Inactive**. Это нормально: пока ни один компьютер не подключён.

Windows-ноутбук недоступен? Достаточно, чтобы он был выключен во время уроков.

---

## Часть 2. Homebrew на Mac (если его нет)

Homebrew — установщик программ для Mac через Терминал. Через него проще всего поставить cloudflared.

1. Откройте **Терминал**: Cmd+Пробел → наберите `Терминал` (или `Terminal`) → Enter.
2. Проверьте, есть ли Homebrew:
   ```
   brew --version
   ```
   - Показало версию (`Homebrew 4…`) → переходите к Части 3.
   - Пишет `command not found` → ставим дальше.
3. Откройте https://brew.sh, скопируйте длинную команду под заголовком «Install Homebrew» (начинается с `/bin/bash -c "$(curl`), вставьте в Терминал, нажмите Enter.
   - Спросит **пароль от Mac**. При вводе символы не видны — это нормально. Введите и нажмите Enter.
   - Попросит нажать **Enter** для продолжения — нажмите.
   - Может предложить установить «Command Line Tools» — соглашайтесь и ждите. Установка займёт 5–10 минут.
4. **Важно для M1.** В конце Homebrew напишет блок **Next steps** с двумя-тремя командами (начинаются с `echo` и `eval`). Скопируйте и выполните их по очереди, иначе команда `brew` не будет находиться. Обычно это:
   ```
   echo >> ~/.zprofile
   echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
   eval "$(/opt/homebrew/bin/brew shellenv)"
   ```
5. Проверьте ещё раз: `brew --version` должно показать версию.

## Часть 3. Туннель на Mac

1. Установите cloudflared:
   ```
   brew install cloudflared
   ```
   Проверка: `cloudflared --version` показывает версию.
2. Откройте **dash.cloudflare.com → Networking → Tunnels → `stream_vr`** → кнопка **Add a replica** (Добавить реплику).
3. Выберите систему **macOS**. Cloudflare покажет команды. Нужна та, что начинается с:
   ```
   sudo cloudflared service install eyJ...
   ```
   `eyJ…` — длинный токен, это пароль туннеля. Копируйте команду целиком через кнопку копирования справа. **Никому не пересылайте и не выкладывайте её в GitHub.**
4. Вставьте команду в Терминал и нажмите Enter. Спросит пароль от Mac (символы не видны) — введите и нажмите Enter.
5. Через 30–60 секунд в Cloudflare в **Replicas** появится строка с именем вашего Mac, а статус туннеля станет **Healthy**.

Туннель теперь запускается сам при каждом включении Mac, отдельно его запускать не нужно.

**Маршрут проверять не нужно, он уже есть:** вкладка **Routes** → `stream.orikly.org` → `http://127.0.0.1:8090`, тип **HTTP**. Если по какой-то причине его нет, создайте: **Add route → Published application** → Subdomain `stream`, Domain `orikly.org`, Service URL `http://127.0.0.1:8090` (**HTTP, не HTTPS**).

> **Если создаёте туннель с нуля** (например, удалили старый): Networking → Tunnels → **Create a tunnel** → **Cloudflared** → имя `stream_vr` → Save → выберите **macOS** → выполните показанную команду `sudo cloudflared service install eyJ...` (п. 4 выше) → когда появится Connected, нажмите **Next** → добавьте маршрут, как в абзаце выше. Секрет `RELAY_URL` в GitHub при этом не меняется: адрес остаётся `wss://stream.orikly.org/push`.

## Часть 4. Обновить проект в GitHub (чтобы Mac-версия была в релизах)

1. Распакуйте архив обновления. В корне репозитория: **Add file → Upload files** → перетащите папку `orikly-pack` → **Commit changes**.
2. Замените файл сборки: откройте в репозитории `.github/workflows/build.yml` → карандаш (Edit) → выделите всё (Cmd+A) и удалите → вставьте содержимое `build.yml` из архива → **Commit changes**.
3. **Actions → Build APK → Run workflow** → версия больше прошлой (например, `0.3.4`) → **Run workflow**.
4. Через 5–10 минут в **Releases** появится версия с тремя файлами: `orikly-quest-stream.apk`, `orikly-server.exe` и **`orikly-server-mac.zip`**.

Можно не ждать сборку: `orikly-server-mac.zip` уже лежит в архиве обновления.

## Часть 5. Программа-сервер на Mac

1. Возьмите `orikly-server-mac.zip` (из архива или из Release) и распакуйте двойным кликом. Появится файл `orikly-server-mac`.
2. В Finder создайте папку **Документы → Orikly** и перенесите туда `orikly-server-mac`.
   Если от Windows остался файл `orikly-server.json` с ключом, положите его в эту же папку. Тогда ключ спрашивать не будут.
3. **Снимите запрет macOS на запуск** (один раз). macOS блокирует программы из интернета без подписи Apple. В Терминале наберите, **поставив в конце пробел**:
   ```
   xattr -d com.apple.quarantine 
   ```
   Затем перетащите файл `orikly-server-mac` из Finder в окно Терминала: путь подставится сам. Нажмите Enter.
   - Ничего не написал или написал `No such xattr` → всё хорошо.

   Другой способ без Терминала: двойной клик по файлу → macOS скажет, что не может проверить разработчика → **Системные настройки → Конфиденциальность и безопасность** → внизу **«Всё равно открыть»** → подтвердите паролем.
4. **Двойной клик по `orikly-server-mac`.** Откроется окно Терминала с текстом `Orikly server is running…`.
   - При первом запуске, если нет `orikly-server.json`, программа спросит ключ: `Enter the access key…`. Введите **точно тот же** ключ, что в секрете `STREAM_KEY` на GitHub, и нажмите Enter. Он сохранится в `Документы/Orikly/orikly-server.json`.
5. Сам откроется Chrome со страницей `http://localhost:8090`. Если Chrome не открылся, откройте его и введите этот адрес вручную.
6. **Окно Терминала не закрывайте**: пока оно открыто, сервер работает. Пока программа запущена, Mac не засыпает. **Крышку не закрывайте.**

## Часть 6. Проверка туннеля

При запущенном `orikly-server-mac` откройте в Chrome:
```
https://stream.orikly.org/push
```
- **`forbidden`** → всё работает (сервер ответил через интернет и отказал, потому что нет ключа — так и должно быть).
- **502** → туннель работает, но сервер не отвечает: не запущен `orikly-server-mac`, или в маршруте указан HTTPS вместо HTTP.
- **1033 / 530** → туннель не подключён: в Replicas нет вашего Mac (Часть 3).

## Часть 7. Очки

1. Очки должны быть на версии **0.3.3 или новее** (внизу экрана приложения Orikly Stream). HMS обновляет сам по той же ссылке.
2. На **каждых** очках один раз: **Orikly Stream → Iniciar transmisión → Pantalla completa → Empezar**.
3. На экране приложения должно появиться **Servidor: conectado** (в течение 30 секунд).
4. В окне Терминала на Mac появятся строки `connected: Quest 3 [1a2b] ...` — по одной на каждые очки.

---

## Часть 8. Страница: имена, папка для записей

1. На странице появятся плитки **Quest 3 · 1a2b**: одна на каждые очки.
2. **Переименуйте:** клик по названию плитки → впишите `Q3-01` → OK. Чтобы понять, какая плитка какие очки: нажмите **Start** на плитке и подвигайте головой в одних очках — «оживёт» нужная. Имена запоминаются на этом Mac.
3. **Папка для записей:** установите «Google Drive для компьютера» (google.com/drive/download) и войдите аккаунтом ассоциации. На странице нажмите **Choose folder…** → в окне выбора слева **Google Drive** → нужная папка → **Выбрать**. При первом Start Chrome спросит разрешение на запись — разрешите.
   - **Если Chrome пишет, что папку открыть нельзя, потому что там системные файлы.** На Mac Google Диск лежит внутри системной папки. Тогда:
     1. В Finder создайте папку **Фильмы → Orikly записи** и выберите её на странице.
     2. Google Drive (значок в строке меню сверху) → шестерёнка → **Настройки** → **Мой Mac / My Mac** → **Добавить папку** → выберите **Orikly записи** → **Синхронизировать с Google Диском** → Готово.
     Записи будут сами уезжать на Диск.

## Каждый урок

1. Mac подключён к интернету с iPhone (Режим модема).
2. Двойной клик по **Документы/Orikly/orikly-server-mac** — откроется Chrome.
3. Плитки появятся сами. Нажмите **Start all**: пойдёт картинка и запись.
   - Клик по картинке — на весь экран в лучшем качестве, Esc — назад.
   - Снимите галочку **Record**, если нужен только просмотр.
4. В конце **Stop all** (файлы сохранятся), потом закройте окно Терминала.

На очках ничего не нажимаете, пока они не перезагрузятся.

---

## Что показывают плитки

- **Streaming · 10 fps** — сколько кадров в секунду реально доходит.
- **⏱ 250 ms** — отклик канала очки → Mac. Нормально 100–400 мс.
- **⚠ quality −2** — очки снизили качество, чтобы держать 10 кадров/с: интернет на пределе.
- **Offline — headset not connected** — очки не подключены (выключены, нет Wi-Fi или не запущен захват).
- **Capture stopped — tap Iniciar on headset** — захват на очках остановился (перезагрузка, каст Meta). Нажмите Iniciar на этих очках.

## Если что-то не работает

| Что видно | Причина и что делать |
|---|---|
| Страница пишет «Server program is not running» | Не запущен `orikly-server-mac` — двойной клик по нему. |
| В Терминале `address already in use` | Сервер уже запущен в другом окне Терминала. Закройте лишнее окно. |
| macOS: «Не удаётся открыть… разработчик не может быть проверен» | Часть 5, пункт 3. |
| `https://stream.orikly.org/push` → 502 | Сервер не запущен, или маршрут указан как HTTPS/localhost. Должно быть `http://127.0.0.1:8090`. |
| → 1033 / 530 | Туннель не на этом Mac. Часть 3; в Replicas должен быть Mac со статусом Healthy. |
| Часть очков не появляется, а в Replicas два компьютера | Туннель всё ещё включён на Windows. Часть 1. |
| На очках «Servidor: conectando…», а в Терминале `rejected a headset with a wrong key` | Ключ в `orikly-server.json` не совпадает со `STREAM_KEY`. Откройте файл в TextEdit (правой кнопкой → Открыть в программе → TextEdit), исправьте ключ, сохраните, перезапустите программу. |
| Задержка растёт, на плитках «⚠ quality −4» и ниже | Интернета iPhone не хватает на все очки. Сделайте speedtest на iPhone в классе и пришлите цифры. |
| После `brew install` пишет `brew: command not found` | Не выполнены команды «Next steps» (Часть 2, п. 4). |
